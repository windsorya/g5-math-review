**3. 推薦設計與有限驗收矩陣**

核心介面應拆成：

```js
analyzeShown({ q, opts })   // 不接收 chk、a、why、hint
verifyCard(card)           // 最後才比對 a，以及 chk 的一致性
```

`analyzeShown()` 必須回傳解析結果、每個選項的真假、正解索引集合及問題原因。驗收条件是：

```js
assert.deepEqual(report.correctIndices, [card.a]);
assert.deepEqual(report.issues, []);
```

其中還有四個必要約束：

- **解析完整句子。** 保留左右運算元、分數分子分母、運算符、否定詞、且／或、最大／最小、單位及幾何限定條件。不能只抽數字，也不能解析失敗後退回 chk。
- **判定每個選項。** 零個成立、多個成立都拒絕；比較的是數學意義，不能只靠字串去重。極值题還要檢查完整題目資料有沒有並列。
- **chk 降為核對資料。** 題文解析出的欄位再與 chk 對應比較；題幹資料不得拿選項數字補齊。`divides`、`triok`、`maxfrac` 的運算資料本來就在選項，必須明確按該角色解析。
- **fact 綁定完整審定內容。** 審定紀錄包含完整題文、全部選項及各選項真假；允許重排後重新定位答案。`id` 只能用來找紀錄，不能代替內容比對。新增或改寫題目未審定就拒絕，不能自動接受新快照。

各類獨立判準：

| 類別 | 涵蓋 k 與判準 |
|---|---|
| 折線 | `argmax`、`maxrise`、`firstdown`：解析有序標籤與數值；分別算最大值、正向增量、選項指定區段是否下降。 |
| 因倍數 | `isfactor`、`nfactors`、`gcd`、`iscommonfactor`、`divides`、`ismultiple`、`lcm`、`rule`：以有限枚舉／整除判定，並解析題文的且、或、否定及最大／最小要求。 |
| 幾何 | `vertices`、`triok`、`third`、`anglesum`、`regangle`、`missing`、`axes`：頂點數、嚴格三角不等式、內角和及受限定的圖形性質；資料不足或圖形名稱有歧義就拒絕。 |
| 分數 | `expand`、`simplify`、`equiv`、`compare`、`maxfrac`、`addsub`：用整數交叉乘與精確有理數運算；是否要求最簡分數，以題文為準。 |
| 觀念 | `fact`：完整人工答案鑰；幾何計算可輔助覆核，不能用未經證明的單一代表圖形代替所有情況。 |

特別注意：目前 `firstdown` 的題文是「哪一段是下降的」，**沒有說第一段**。[mathbank.js:83](/Users/william/Documents/g5-math-review/src/mathbank.js:83) 新驗算必須依實際問法判斷，不能沿用 k 名稱的隱藏語意。
